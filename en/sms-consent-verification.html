2. SMS Opt-In Process

Clients opt in to SMS notifications through their account profile in the scheduling system. This is a voluntary, explicit opt-in that requires:

  1. User must be logged into their authenticated account at schedule.opengateways.com
  2. User navigates to Profile → Communication Preferences section
  3. User clicks the SMS checkbox which opens a consent dialog
  4. User reviews and confirms all consent disclosures in the modal
  5. User checks the consent confirmation checkbox
  6. User clicks "Enable SMS" button to complete opt-in

4. Message Frequency

Typical message volume per scheduled appointment:

  • Confirmation: 1 message when appointment is booked
  • Reminder: 1 message (typically 24 hours before, user-configurable)
  • Payment: 1-2 messages (confirmation and/or reminder if applicable)
  • Cancellation: 1 message (if appointment is cancelled)

Average: 2-4 messages per scheduled appointment

No marketing or promotional messages are sent via SMS.

5. Opt-Out Mechanism

Users can opt out of SMS notifications at any time via:

  • Reply STOP: Immediately removes user from SMS list. Automatic unsubscribe confirmation sent.
  • Reply HELP: Receives assistance message with contact info and instructions
  • Account Settings: Disable SMS checkbox in Communication Preferences at any time
